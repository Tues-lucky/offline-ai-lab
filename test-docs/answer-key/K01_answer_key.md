# K01 연구용역 계약서: answer key (traps)

Do not put this file in the knowledge base you are testing.

| # | Question (Korean) | Correct answer | Trap |
|---|---|---|---|
| 1 | 계약금액은 얼마이고 부가가치세는 포함인가? | 48,000,000원. 제4조 ①은 "부가가치세 별도", 별표 2 제목은 "부가가치세 포함". **충돌**이므로 둘 다 인용해야 함 | Body vs schedule conflict (VAT) |
| 2 | 최종 보고서 납품 기한은 언제이고 계약기간 안에 있는가? | 별표 1: 2027-07-15. 제3조 계약기간은 2027-06-30까지. **납품 기한이 계약기간 이후** | Date conflict (schedule vs body) |
| 3 | 잔금은 얼마이고 언제 받나? | 40%, 19,200,000원, 3단계 완료 후 청구, 청구일부터 30일 이내 지급 (별표 2 + 제5조 ①) | Needs table + clause |
| 4 | 응답자 개인정보는 언제까지 파기해야 하나? | 용역 종료일부터 30일 이내, 파기 확인서 제출 (제6조 ②) | Single lookup |
| 5 | 납품이 20일 늦으면 지체상금은? | 1일 1/1000 × 20일 = 계약금액의 2% = 960,000원 (상한 10%) (제8조) | Arithmetic |
| 6 | 분쟁은 법원으로 가나, 중재로 가나? | 제11조 ②는 갑 본점 소재지 법원, ③은 대한상사중재원 중재로 "최종 해결". **충돌**이므로 둘 다 언급해야 함 | Internal conflict |
| 7 | 을(수행자)이 계약을 해지할 수 있나? | 을의 해지 조항 없음. 갑만 해지 가능, 30일 전 통지로 사유 없이도 가능 (제10조 ②) | Risk spotting (one-sided) |
| 8 | 을의 분석 도구에 대한 권리는 누구에게 있나? | 을에게 유보, 갑은 결과물 활용에 필요한 범위에서 사용 가능 (제9조 ②). "필요한 범위"는 해석 여지 있음 | Ambiguous clause |
